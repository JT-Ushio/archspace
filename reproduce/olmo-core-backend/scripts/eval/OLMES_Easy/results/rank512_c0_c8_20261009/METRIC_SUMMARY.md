# Rank512激活与C0–C8：14份OLMES完整结果

这批最值得关注的是C2：数学BPB、QA阅读准确率和QA BPB均为14个模型中最好。代码BPB以C0最好，C6次之，因此没有一个配置在四项都最优。末期Train CE最好的C6，在这次benchmark中没有统一优于C2。

QA RC的均匀随机选择参考约为28.18%，不是固定25%。按本次实际评测的83个叶任务逐题候选项数计算，再按21个顶层任务组递归等权宏平均；开放词表末词预测LAMBADA的随机命中率近似按0计，其他任务按有效正确选项数/候选项数计。二选一为50%，三选一为33.33%，四选一为25%，五选一为20%。这是计算得到的随机猜测期望，未运行随机模型；C2的47.704%比该近似参考高19.52个百分点。[逐任务计算记录](QA_RC_RANDOM_CHANCE.json)。

对原始5个独立rank512模型：Full-Linear在四项都优于CoLA；RMS@Down在四项都改善CoLA，但仍不如Full-Linear。Q-only的代码BPB最低，K-only的数学和QA BPB最低，Full-Linear的QA RC最高。Q/K单点SiLU不能概括成所有benchmark都改善。

对组合组：C2相较C0，数学及两项QA改善，代码BPB变差；这比较的是同预算UG共享与秩再分配的整体组合，不能把所有差异单独归因于共享。C2/C6/C8矩阵形状一致，分别为K SiLU、Q/K SiLU、Q/K Linear，Down均为RMS。C2在数学和QA更好，C6在代码更好。
