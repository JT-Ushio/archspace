# 随机 dense-SVD 初始化：step0 统计解读

这不是最终训练报告。A/C 的30B训练仍在进行；以下仅解释初始化干预实际改变了什么。

## 数据与对照

- A：原始 encoder/decoder 独立初始化。
- B：新随机 dense W 的平衡截断 SVD，仅作 step0 诊断。
- C：与 B 相同的 SVD，再分别匹配原始 encoder/decoder 的权重 RMS。
- 三组都是 rank512，Down 为无可学习 gain 的 RMSNorm，其余低秩中间激活为 SiLU；主 SwiGLU 门控不变。
- 112个投影（16层×7类）、32条固定8K序列，共64512条逐序列激活统计。相同序列分别运行 BF16/FP8。
- 原始数据：[weights.csv](results/svd-init-r512-20260913-v3/weights.csv)、[activation_summary.csv](results/svd-init-r512-20260913-v3/activation_summary.csv)、[原始报告](results/svd-init-r512-20260913-v3/REPORT.md)。
- 完整性：成功的 v3 probe、8个 worker 的实际 FP8/compile/FSDP 因子装载回读检查均通过；manifest SHA256 为 `64dd7689a0b3f3e8f989507552f4288f5c91f43e1f1696d9ebc6ebc02ac62bc3`。

## 1. 因子尺度匹配成功，但谱结构明显不同

全部112对因子中，C/A 的 encoder/decoder RMS 最大相对偏差为 `9.4541e-8`。
因此不是简单把整个 encoder 或 decoder 的权重幅度放大/缩小来构造 C。

下表是每类16层的等权平均。条件数定义为 **DE 的512个非零奇异值中最大/最小之比**；DE 本身是低秩矩阵，不能把该数称为完整 dense 矩阵的有限条件数。

| 投影 | 随机 W 截断至512维保留能量 | A：DE非零谱条件数 | C：DE非零谱条件数 |
|---|---:|---:|---:|
| Q | 62.308% | 4.729 | 1.573 |
| K | 62.290% | 4.694 | 1.571 |
| V | 62.285% | 4.717 | 1.570 |
| O | 62.311% | 4.682 | 1.571 |
| Gate | 42.667% | 3.331 | 1.281 |
| Up | 42.664% | 3.323 | 1.281 |
| Down | 42.668% | 3.344 | 1.282 |

保留能量是对生成的随机 W 的统计，不是对 A 的压缩质量评价。分别标量缩放 E/D 不改变 DE 非零谱条件数，因此 B/C 在这个指标上相同。

C 的有效线性方向更均衡，是本次干预的明确特征。但是实际映射是 `D φ(E x)`，不是 `DE x`。其 Jacobian 还包含激活导数（Down 则包含 RMSNorm Jacobian），不能从 DE 的谱直接推断实际梯度条件数或最终泛化效果。

## 2. 激活尺度总体接近，但并不完全相同

定义 `a=E x`、`z=φ(a)`、`y=D z`。下表先计算每层同一阶段 C/A 的序列平均 RMS 比，再对16层取等权平均；不是把所有层的元素混起来算一个 RMS。

| 投影 | a 的 C/A RMS比 | z 的 C/A RMS比 | y 的 C/A RMS比 |
|---|---:|---:|---:|
| Q | 1.00035 | 1.00276 | 1.01041 |
| K | 0.99914 | 1.00151 | 1.00862 |
| V | 0.99108 | 0.98664 | 0.99799 |
| O | 1.00031 | 0.99023 | 1.00006 |
| Gate | 1.00470 | 1.00324 | 1.00589 |
| Up | 1.00110 | 0.99118 | 0.99498 |
| Down | 1.00206 | 1.00002 | 1.00038 |

这些均值支持“总体尺度相近”，不证明每个 token/通道分布相同，也可能掩盖不同层的相反变化。原始逐层/逐序列数据需保留。后面各层接收的是各自模型的隐藏状态，因此它们不是完全固定输入的单层因果比较。

## 3. 起始 CE 的差异不能当作收敛收益

| 初始化 | BF16 sampled-token CE | FP8 sampled-token CE |
|---|---:|---:|
| A independent | 11.940384 | 11.941447 |
| B raw SVD | 11.859054 | 11.856553 |
| C matched SVD | 11.854536 | 11.854375 |

C 相对 A 起始 CE 低约0.08585（BF16）/0.08707（FP8）。这是固定序列上抽样位置的 step0 CE，不是完整 validation CE，也不是学习到知识的证据。BF16/FP8 下该差异接近，说明本次起点差异并非只在 FP8 路径出现；不能据此排除后续 FP8 数值影响。

## 后续判断标准

主结论等待 A/C 相同 tokens 的 validation CE；同时报告各数据源、完整曲线及最后100/500/1000步 train CE。若 C 只在起点较好、随后差距消失，应表述为起点效应；若优势持续到30B，再考虑配对 seeds 验证。

本轮同时改变了方向相关性、谱和非线性坐标系，尚不能单独证明“条件数改善导致收益”。随机 W 没有预训练知识，本实验也不是 SVDLLM/PCA 的预训练模型压缩实验。未经训练结果支持，不追加 B 的完整训练。
